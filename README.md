# UserGlobalSearch

Символ `&` в быстром поиске Discord (Ctrl+K): глобальный поиск пользователей и их сообщений по всем общим серверам и чатам, прямо в нативном окне Discord.

## Что это

BetterDiscord плагин. Добавляет в Quick Switcher новый триггер `&` рядом с родными `@ # ! * $`:

| Ввод | Что делает |
|------|------------|
| `&` | Список всех пользователей, друзья сверху |
| `&ник` | Поиск пользователя: друзья, личка, общие серверы |
| `&ник ` (с пробелом) | Свежие сообщения этого человека везде, где вы состоите |
| `&ник текст` | То же самое, но с фильтром по тексту |

Enter по человеку открывает его сообщения, Enter по сообщению прыгает к нему в чат без перезагрузки клиента.

## Почему выглядит как часть Discord

Выдача рисуется внутри нативного окна Quick Switcher родными классами Discord: тема, шрифты, отступы и hover применяются сами, включая кастомные темы. Символ `&` дописывается в строку подсказки рядом с `@ # ! * $`.

## Возможности

- Поиск людей: начало слова, подстрока, акроним, транслит (`соня` находит `Sonya` и наоборот). Случайный набор букв ничего не находит, ложных совпадений нет.
- Аватарки с точкой статуса, бейджи ДРУГ / СЕРВЕР ×N / ЛС / БОТ, строка контекста «Друг · 3 сервера · ЛС», подсветка совпавших букв.
- Поиск сообщений идёт через внутренний REST-модуль Discord, тот же, что у самого клиента: параллельные запросы, отмена при новом вводе, обработка rate limit, кэш последнего запроса.
- Иконки серверов и чатов в результатах сообщений.
- Клавиатура: ↑/↓ выбор, Enter открыть, Tab из имени в сообщения, Esc закрыть.
- Настройки в стиле Discord: тумблеры и слайдеры, разделы Поиск / Интерфейс / Поиск сообщений / Служебные, сброс к дефолтам.
- Самодиагностика одной кнопкой: проверка модулей, движка и рендера, отчёт копируется в буфер обмена.
- Все языки Discord (33 локали). Язык подхватывается из клиента и меняется на лету, без перезапуска.

## Установка

1. Скачайте `UserGlobalSearch.plugin.js` из этого репозитория.
2. Киньте файл в папку плагинов BetterDiscord: Настройки → Плагины → «Открыть папку плагинов».
3. Включите тумблер у UserGlobalSearch.
4. Ctrl+K → введите `&`.

## Настройки

Настройки → Плагины → UserGlobalSearch:

- размер выдачи, задержка поиска, транслитерация;
- друзья первыми, учёт лички и участников серверов;
- точка статуса, бейджи, @username, строка контекста, компактный режим;
- лимиты поиска сообщений, параллельность запросов, режим «только серверы»;
- самодиагностика и сброс настроек.

## Если что-то не работает

Настройки → Плагины → UserGlobalSearch → «Запустить самотест», затем «Скопировать отчёт» и пришлите его в Issues. Отчёт показывает, какой модуль Discord не нашёлся в вашей сборке, без копания в консоли.

## Тесты

node --test tests/*.test.js

Движок, рендер и интеграция с Quick Switcher покрыты тестами на чистом Node, без Discord и jsdom.

## Ограничение

Discord не отдаёт сообщения серверов, где вы не состоите. Это ограничение API, обойти его нельзя. Плагин покрывает личку, группы и общие серверы выбранного человека.
